⚡ GraphQL

Как работает: Клиент отправляет запрос с описанием нужных данных, сервер возвращает ровно их.

❌ Over‑fetching — лишние данные
❌ Under‑fetching — не хватает данных, нужно несколько запросов
✅ GraphQL решает: один запрос → ровно то, что нужно

🚀 gRPC и Protocol Buffers

Что такое: gRPC — высокопроизводительный фреймворк от Google. Protocol Buffers (protobuf) — язык описания данных, бинарный и быстрый.

Почему стандарт для микросервисов на Python:

  • ⚡ Высокая скорость (бинарный протокол)
  • 📦 Компактный размер сообщений
  • 🔁 Поддержка двунаправленной потоковой передачи
  • 🧩 Строгая типизация и генерация кода
  • 🌍 Кросс‑языковая совместимость

🐍 Версионирование API и пагинация в Python

Версионирование

  • URL: /api/v1/users
  • Query‑параметр: ?version=1
  • Заголовок: Accept-Version: 1
  • В FastAPI / Django — через роутинг

Пагинация

  • Page/Size: ?page=2&size=10
  • Limit/Offset: ?limit=10&offset=20
  • Cursor‑based: ?cursor=abc123
  • В Python: limit() в SQLAlchemy, Paginator в Django
